# ♞ Шахматы для Telegram

Mini App для Telegram: онлайн-партии на рейтинг Эло, быстрый поиск соперника, дуэли по ссылке и прямые вызовы игрокам, таблица лидеров (за всё время и прирост за неделю), профили со статистикой и историей партий, реванш, чат в партии и игра против компьютера (4 уровня).

## Что внутри

```
server/       сервер на Node.js: HTTP, WebSocket, бот, база SQLite
  index.js    точка входа, API и раздача файлов
  hub.js      онлайн: подключения, очередь поиска, вызовы, партии
  game.js     партия: часы, ходы, ничья, сдача, отключения, сохранение
  bot.js      бот: /start, /top, /duel, ссылки-вызовы, уведомления
  db.js       база данных (встроенный в Node модуль node:sqlite)
  auth.js     проверка подписи initData от Telegram
  elo.js      расчёт рейтинга
shared/       общий код для сервера и браузера
  chess.js    правила шахмат (проверены perft-тестами)
  engine.js   движок для игры против компьютера
public/       Mini App (HTML, CSS, JS без сборки)
deploy/       скрипт установки, служба systemd, конфиг nginx
```

Внешняя зависимость одна — `ws` (WebSocket). Нужен Node.js 22.5 или новее.

## Правила онлайн-игры

- Рейтинг Эло, старт 1200. Коэффициент K = 40 для первых 30 партий, затем 20 (10 для рейтинга от 2400).
- Часы запускаются после первого хода чёрных. На первый ход у каждой стороны 30 секунд, иначе партия отменяется без изменения рейтинга.
- Если игрок отключился, у него есть 90 секунд, чтобы вернуться. Иначе ему засчитывается поражение.
- Если время вышло, а у соперника нет материала для мата, это ничья.
- Все ходы проверяет сервер, поэтому подделать ход из браузера нельзя.

## Установка на VPS (Beget)

### 1. Создайте бота
В Telegram откройте @BotFather → `/newbot` → придумайте имя и username. Сохраните токен вида `123456789:AA...`.

### 2. Добавьте поддомен
В панели Beget (раздел DNS вашего домена) создайте A-запись `chess` → IP вашего VPS. Подождите 5–15 минут.

### 3. Загрузите проект на сервер
Через SFTP в Termius загрузите архив `tg-chess.zip` в домашнюю папку, затем:

```bash
sudo apt-get install -y unzip
unzip -o tg-chess.zip -d ~/
cd ~/tg-chess
```

### 4. Запустите установку

```bash
sudo bash deploy/install.sh chess.example.com 123456789:ВАШ_ТОКЕН
```

Скрипт поставит Node.js 22, зависимости, службу `tg-chess`, nginx и бесплатный HTTPS-сертификат.

### 5. Настройте Mini App в BotFather
- `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → адрес `https://chess.example.com`, название `Играть`.
- `/newapp` → ваш бот → название, описание, картинка 640×360, GIF `/empty`, адрес `https://chess.example.com`, короткое имя `play`.

Затем сообщите серверу username бота и короткое имя приложения, чтобы ссылки-вызовы открывали приложение напрямую:

```bash
sudo bash deploy/install.sh chess.example.com 123456789:ВАШ_ТОКЕН имя_бота play
```

### 6. Проверьте
Откройте чат с ботом и нажмите кнопку «Играть».

### Если сервер не может связаться с api.telegram.org
Mini App, вход и онлайн-игра работают и без этого: кнопку и ссылку на приложение даёт BotFather (шаг 5). Не будут работать только ответы бота на команды и уведомления о вызовах. Чтобы вернуть их, укажите в `.env` адрес прокси к Bot API на сервере за рубежом: `TELEGRAM_API=https://ваш-прокси`.

### Обновление
Загрузите новый архив, распакуйте его поверх старого и запустите `sudo bash deploy/install.sh` без параметров. База и настройки сохранятся.

### Полезные команды

```bash
journalctl -u tg-chess -f          # логи в реальном времени
sudo systemctl restart tg-chess    # перезапуск
curl localhost:8090/api/health     # проверка: сколько игроков онлайн
sudo cp /opt/tg-chess/data/chess.db ~/chess-backup.db   # резервная копия базы
```

### Если порты 80/443 уже заняты
Если на VPS уже работает другой сервер, который сам слушает 80/443, скрипт не станет настраивать nginx и сообщит об этом. Сервер шахмат при этом уже работает на `127.0.0.1:8090`. Нужно, чтобы программа на 443-м порту передавала запросы для `chess.example.com` на этот адрес, включая WebSocket по пути `/ws`.

Для **Caddy** достаточно добавить в `/etc/caddy/Caddyfile` блок и перезагрузить Caddy (WebSocket и сертификат он настроит сам):

```
chess.example.com {
    reverse_proxy 127.0.0.1:8090
}
```

```bash
caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy
```

## Проверка без Telegram

```bash
DEV_MODE=1 BOT_TOKEN= npm start
# откройте http://localhost:8090/?dev=1&name=Алиса и во второй вкладке ?dev=2&name=Борис
```

В режиме `DEV_MODE=1` вход возможен без Telegram, поэтому на боевом сервере он должен быть выключен.

## Ограничения текущей версии

- Активные онлайн-партии хранятся в памяти. При перезапуске сервера идущие партии прерываются (завершённые сохраняются в базе).
- Наблюдение за чужими партиями, турниры и ежедневные задачи пока не реализованы.
